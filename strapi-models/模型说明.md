# CUSTMC Strapi 数据模型说明

## 使用方式

把 `strapi-models/src` 下的内容复制到你的 Strapi 项目的 `src` 目录，然后重启 Strapi。

```bash
cp -R strapi-models/src/* /你的/strapi项目/src/
npm run develop
```

## 建议录入顺序

1. `site-setting`
2. `maintenance-page`
3. `external-service`
4. `tag`
5. `activity`、`announcement`、`club-post`、`member-profile`、`gallery-item`
6. `home-page`
7. `about-page`
8. `join-page`

`home-page` 依赖活动、公告、动态、社员和图库的精选关系，所以建议先录集合内容，再配置首页。

## Single Types

| Strapi 模型 | 用途 | 对应前端数据 |
| --- | --- | --- |
| `site-setting` | 全站基础配置、品牌、SEO、导航、页脚关于我们链接、版权和署名 | `SiteInfo`、`NavLink[]` |
| `maintenance-page` | 维护模式、维护页文案、预计恢复时间和服务状态 | `MaintenancePageData`、`ServiceStatus` |
| `home-page` | 首页 Hero、简介、服务器概览、精选内容 | `HomeData.hero`、`HomeData.intro`、`HomeData.server` |
| `about-page` | 社团介绍页 | `AboutPageData` |
| `join-page` | 加入我们页 | `JoinPageData` |

## Collection Types

| Strapi 模型 | 用途 | 对应前端数据 |
| --- | --- | --- |
| `activity` | 社团活动 | `ActivitySummary` |
| `announcement` | 社团公告 | `AnnouncementSummary` |
| `club-post` | 社团动态、教程、建设记录 | `PostSummary` |
| `member-profile` | 公开社员资料 | `MemberProfile` |
| `gallery-item` | 首页精彩瞬间、作品图集入口 | `GalleryItem` |
| `external-service` | 皮肤站、文档中心、MUA 官网、悦灵助手等公开外部服务或服务入口 | `ExternalService[]` |
| `tag` | 动态、活动复用标签 | `Tag` |

## 字段适配注意

- Strapi 的发布系统自带 `publishedAt`，不要额外创建同名字段。
- Strapi 的媒体字段需要在 Nuxt Server Routes 中规范化为 `{ src, alt }`。
- `footerAboutLinks` 需要映射为结构化页尾“关于我们”链接数组；页尾“外联”栏目来自 `external-service.showInFooter = true` 的条目。
- `skinConsoleUrl`、`documentCenterUrl`、`footerExternalLinks`、`serviceStatus*` 和 `maintenance*` 不再作为 `site-setting` 的长期职责，分别迁移到 `external-service` 和 `maintenance-page`。
- `heroTitleLines`、`requirements`、`process-step.items` 等 repeatable `text-item` 组件需要映射为字符串数组。
- `heroSlides.overlayMode` 用于控制首页 Hero 遮罩行为：品牌主视觉使用 `side`，氛围图使用 `edge`，展示型图片可使用 `corner`、`local` 或 `none`；`corner` 通过 `overlayAnchor` 指定轻暗角位置，`local` 只保留文字描边和阴影、不显示文字背景面板，避免用大面积暗角压暗需要展示的画面主体。
- `heroSlides.photoLocation` 和 `heroSlides.photoAuthor` 用于首页 Hero 可见图片图注；`heroSlides.photoCaptionPosition` 控制图注角落位置并默认使用 `auto`，由前端避开 Hero 主标题所在角落；缺省图注文案规范化为空字符串，不通过 Markdown、图片文件名或 Hero 标题文案维护。
- `process-step.image` 需要在 Nuxt Server Routes 中规范化为 `{ src, alt }`；`imageAlt` 优先作为步骤图片替代文本，`imageCaption` 作为页面可见说明。
- `process-step.primaryActionLabel` 和 `process-step.primaryActionUrl` 用于加入流程等页面的可选动作入口，不应通过 Markdown 拼装按钮。
- `club-post.tags` 是标签关系，前端筛选用字符串时可映射为 tag 的 `name` 或 `slug`。
- `member-profile.works` 和 `promo-section.tags` 使用 JSON 数组，方便直接匹配当前前端类型。
- 公开接口只返回已发布内容；`member-profile` 还要额外过滤 `isVisible = true`。
- 标题、摘要、时间、状态、标签、图片、链接、排序、精选关系、导航、服务入口、流程步骤图片、流程步骤条目、流程步骤动作入口和组件配置使用结构化字段；活动详情、公告正文、社团动态正文、社团介绍正文和加入说明正文使用 Markdown/richtext。
