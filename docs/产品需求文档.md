# 长春理工大学 Minecraft 社团官网产品需求文档

## 1. 项目定位

长春理工大学 Minecraft 社团官网用于展示社团形象、发布社团信息、介绍服务器内容，并为游客、社员和管理员提供不同的访问入口。

系统由三部分组成：

- 官网前台：面向游客、校内学生、校外访问者和潜在新成员。
- 社员中心：面向已登录社员，提供皮肤站控制台入口和后续社内服务入口。
- 内容后台：面向具有权限的社员，用于维护官网内容。

第一阶段允许使用 Strapi 作为 CMS 系统管理内容；后续可在内容模型稳定后迁移为自研后台。

## 2. 核心目标

- 建立社团统一的线上展示入口。
- 展示社团介绍、活动、公告、动态、社员介绍、服务器信息和作品内容。
- 支持社员登录后进入服务器皮肤站控制台。
- 支持有权限的社员进入内容后台维护官网内容。
- 形成可长期维护、可扩展的内容管理体系。

## 3. 用户角色

| 角色 | 说明 | 核心权限 |
| --- | --- | --- |
| 游客 | 未登录访问者 | 浏览公开页面 |
| 社员 | 已登录社团成员 | 进入社员中心和皮肤站控制台 |
| 内容管理员 | 具有内容管理权限的社员 | 管理活动、公告、动态、社员介绍等内容 |
| 超级管理员 | 系统最高权限用户 | 管理全部内容、账号、权限和站点配置 |

普通社员默认不能进入内容后台，也不能发布、编辑或删除官网公开内容。

## 4. 官网前台页面

本节描述官网前台需要承载的展示内容。是否在第一阶段拆成独立页面，以本文档“第一阶段范围”和详细设计文档为准。

### 4.1 首页

首页承担第一印象和主要入口功能。

应展示：

- 社团品牌标识。
- Hero 主视觉。
- 社团简介。
- 近期活动。
- 最新公告。
- 最新动态。
- 服务器状态或服务器介绍。
- 精彩瞬间或作品展示。
- 社员介绍入口。
- 加入社团入口。
- 登录入口。
- 页脚联系方式。

### 4.2 社团介绍页

用于说明社团背景、社团方向、社团文化和主要分组。

应展示：

- 社团简介。
- 社团文化或口号。
- 主要分组，例如建筑组、红石组、活动组、运维组。
- 社团服务器或代表性项目。
- 加入引导。

### 4.3 社团活动页

用于展示近期活动和历史活动。

活动内容应包含：

- 活动标题。
- 活动日期。
- 活动状态。
- 活动简介。
- 活动封面图。
- 活动详情。
- 报名入口或外链。

### 4.4 社团公告页

用于发布正式通知、服务器维护说明、活动结果和重要更新。

公告内容应包含：

- 公告标题。
- 发布时间。
- 公告分类。
- 正文内容。
- 发布状态。
- 置顶设置。

公告具有正式通知属性，应与社团动态区分。

### 4.5 社团动态页

用于发布社团博文、社团日常、服务器记录、成员创作进展和活动花絮。

动态内容应包含：

- 动态标题。
- 发布时间。
- 分类标签。
- 封面图或配图。
- 正文内容。
- 作者或发布人。
- 发布状态。

### 4.6 社员介绍页

用于展示社团成员、分组和代表性成果。

社员展示内容应包含：

- 展示名。
- 所属分组。
- 简介。
- 头像或皮肤形象。
- 代表作品或参与活动。
- 展示状态。

第一阶段不展示真实姓名、学号、手机号等敏感信息。社员公开资料默认由管理员维护。

### 4.7 服务器信息展示

用于展示服务器状态和玩法信息。

应展示：

- 服务器名称。
- 服务器地址。
- 支持版本。
- 游戏模式。
- 在线状态。
- 规则说明。
- 加入服务器方式。

第一阶段服务器状态可由管理员手动维护；后续可接入真实服务器状态查询。

### 4.8 资源下载需求

用于统一管理资源包、整合包、地图和说明文档。

资源内容应包含：

- 资源名称。
- 资源分类。
- 版本号。
- 更新时间。
- 简介。
- 下载链接。
- 使用说明。

### 4.9 加入我们页

用于承接新成员转化。

应展示：

- 加入方式。
- QQ 群或其他联系方式。
- 入社说明。
- 服务器加入条件。
- 常见问题。

## 5. 社员中心

社员中心用于承接登录后的普通社员操作，避免所有登录用户直接进入内容后台。

应包含：

- 当前账号信息。
- 皮肤站控制台入口。
- 可访问服务列表。
- 个人公开资料状态。
- 内容后台入口，仅对内容管理员和超级管理员显示。

皮肤站控制台第一阶段可作为受权限保护的外部入口，不纳入官网 CMS 范围。

## 6. 内容管理需求

后台内容系统采用类 Strapi 的 Headless CMS 设计方式，第一阶段允许使用 Strapi Admin 承担内容管理能力。

后台应支持维护：

- 站点基础信息。
- 首页内容。
- 社团介绍。
- 社团活动。
- 社团公告。
- 社团动态。
- 社员介绍。
- 加入我们页。
- 图片、附件和作品相册。
- 服务器展示信息。
- 资源下载信息，第一阶段可暂缓独立页面。

具体内容模型、字段、接口和媒体规范以详细设计文档为准。

## 7. 设计边界

- 产品需求文档只描述系统目标、用户角色、页面范围和功能边界。
- 技术栈、部署组成和整体架构见总体设计文档。
- 页面详细设计、接口、数据模型、权限、缓存、SEO、媒体规范见详细设计文档。
- 后续自研后台规划见自研后台设计文档。
- 开发风格、注释、命名、提交规范见开发规范文档。

## 8. 第一阶段范围

第一阶段优先完成：

- 官网首页。
- 社团介绍页。
- 活动列表与详情。
- 公告列表与详情。
- 社团动态列表与详情。
- 社员介绍页。
- 加入我们页。
- 社员登录与社员中心。
- 皮肤站控制台入口。
- 内容后台入口。
- 404 页面。
- 维护提示页。
- 服务器信息展示，第一阶段可并入首页或社团介绍页。
- 基础内容管理后台。
- 媒体上传和选择。

第一阶段暂缓：

- 独立服务器信息页。
- 资源下载页。
- 在线报名审核。
- 白名单自动审核。
- 作品投稿。
- 评论、点赞、论坛。
- 实时聊天。
- 复杂审核流。
- 内容版本对比。
- 真实服务器状态查询。
