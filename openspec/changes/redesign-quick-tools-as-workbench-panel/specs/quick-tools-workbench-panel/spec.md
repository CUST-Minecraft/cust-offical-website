## ADDED Requirements

### Requirement: 快捷工具使用居中工作台面板
官网 SHALL 将全站快捷工具展示为居中的工作台面板。访问者点击右下角快捷工具触发器时，系统 MUST 打开该面板，而不是在右下角展开纵向工具按钮列表。

#### Scenario: 打开快捷工具工作台
- **WHEN** 访问者点击右下角快捷工具触发器
- **THEN** 系统 MUST 在页面中间展示快捷工具工作台面板
- **AND** 系统 MUST 保留右下角触发器作为打开入口
- **AND** 系统 MUST NOT 在右下角展示原有纵向堆叠工具按钮列表

#### Scenario: 关闭快捷工具工作台
- **WHEN** 快捷工具工作台面板已经打开
- **THEN** 系统 MUST 提供明确的关闭方式
- **AND** 系统 MUST 支持点击遮罩或按下 Escape 关闭面板
- **AND** 系统 MUST 在关闭后保持当前页面路由不变

### Requirement: 左侧工具列表区分工具类型
快捷工具工作台 SHALL 在左侧展示工具列表。每个工具列表项 MUST 展示图标和工具名称，并且系统 MUST 区分外部工具与站内工具。

#### Scenario: 查看工具列表
- **WHEN** 访问者打开快捷工具工作台
- **THEN** 系统 MUST 在左侧展示“文档中心”“悦灵助手”和“社团服务状态”
- **AND** 每个工具项 MUST 展示对应图标和工具名称
- **AND** 系统 MUST 保持顺序为“文档中心 / 悦灵助手 / 社团服务状态”

#### Scenario: 区分外部工具和站内工具
- **WHEN** 访问者查看左侧工具列表
- **THEN** 系统 MUST 将文档中心标识为外部工具
- **AND** 系统 MUST 将悦灵助手和社团服务状态标识为站内工具
- **AND** 外部工具和站内工具 MUST 通过分组、标记、状态文本或等价视觉方式区分

#### Scenario: 选择工具项
- **WHEN** 访问者选择左侧工具列表中的任一工具
- **THEN** 系统 MUST 将该工具项标记为当前选中状态
- **AND** 系统 MUST 在右侧工具栏位展示所选工具的对应内容

### Requirement: 右侧栏位直接呈现站内工具 UI
快捷工具工作台 SHALL 使用右侧栏位展示站内工具的轻量 UI。悦灵助手和社团服务状态 MUST 能在右侧栏位中直接查看或操作，而不是只显示跳转说明。

#### Scenario: 选择悦灵助手
- **WHEN** 访问者在左侧工具列表选择“悦灵助手”
- **THEN** 系统 MUST 在右侧栏位展示悦灵助手的站内工具 UI
- **AND** 该 UI MUST 检查 Agent 服务状态
- **AND** Agent 服务未配置或不可用时，系统 MUST 在右侧栏位直接展示不可用提示和 fallback 操作
- **AND** Agent 服务可用时，该 UI MUST 至少提供常用指令或对话入口中的一种可操作内容
- **AND** 系统 MUST NOT 将悦灵助手标识为外部系统
- **AND** 系统 MUST NOT 从快捷工具工作台再打开额外的悦灵助手弹窗

#### Scenario: 选择社团服务状态
- **WHEN** 访问者在左侧工具列表选择“社团服务状态”
- **THEN** 系统 MUST 在右侧栏位展示社团服务状态的站内工具 UI
- **AND** 该 UI MUST 展示在线服务数量和服务状态摘要
- **AND** 系统 MUST NOT 将社团服务状态标识为外部系统
- **AND** 系统 MUST NOT 从快捷工具工作台再打开额外的服务状态弹窗

### Requirement: 外部工具通过右侧跳转按钮打开
快捷工具工作台 SHALL 对外部工具展示独立的右侧外部入口栏位。外部工具 MUST 通过右侧明确的跳转按钮打开，不得在选择左侧工具项时立即离开官网。

#### Scenario: 选择外部工具
- **WHEN** 访问者在左侧工具列表选择外部工具
- **THEN** 系统 MUST 在右侧栏位展示该工具的外部系统说明
- **AND** 系统 MUST 展示明确的跳转按钮
- **AND** 系统 MUST NOT 因选择左侧工具项而直接打开外部页面

#### Scenario: 点击外部工具跳转按钮
- **WHEN** 外部工具已配置可用 URL 并且访问者点击右侧跳转按钮
- **THEN** 系统 MUST 打开对应外部系统
- **AND** 系统 MUST 清楚表达该动作会离开当前官网或打开新标签页

### Requirement: 快捷工具工作台适配移动端
快捷工具工作台 SHALL 在移动端保持可读、可点按且不横向溢出。系统 MUST 根据视口调整左侧列表和右侧栏位布局。

#### Scenario: 移动端打开快捷工具工作台
- **WHEN** 访问者在移动端视口打开快捷工具工作台
- **THEN** 系统 MUST 将面板宽度限制在视口安全范围内
- **AND** 系统 MUST 让工具列表和工具栏位均可读
- **AND** 系统 MUST NOT 产生横向滚动或文本明显溢出

#### Scenario: 移动端使用工具
- **WHEN** 访问者在移动端选择工具项
- **THEN** 系统 MUST 展示所选工具的右侧栏位等价内容
- **AND** 系统 MUST 保持主要操作按钮具备可触控尺寸
