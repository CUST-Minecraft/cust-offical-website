## ADDED Requirements

### Requirement: 社团服务工作台内部切换具有连续动效
社团服务工作台 SHALL 在内部服务栏位、服务状态面板和 Agent 状态切换时提供短过渡。动效 MUST 表达当前内容变化，并保持既有服务列表、标题栏状态入口、右侧栏位和移动端布局规则不变。

#### Scenario: 切换文档中心与悦灵助手
- **WHEN** 访问者在社团服务工作台左侧服务列表中切换“文档中心”和“悦灵助手”
- **THEN** 系统 MUST 以短过渡更新右侧服务栏位
- **AND** 系统 MUST 保持左侧服务列表尺寸和右侧栏位容器尺寸稳定
- **AND** 系统 MUST NOT 立即触发文档中心外部跳转

#### Scenario: 打开服务状态面板
- **WHEN** 访问者点击或激活标题栏服务状态入口
- **THEN** 系统 MUST 以短过渡将工作台内容区切换为服务状态面板
- **AND** 系统 MUST 暂时隐藏左侧服务列表和右侧服务栏位的左右分栏结构
- **AND** 系统 MUST NOT 将服务状态表现为左侧服务列表项

#### Scenario: 返回服务列表
- **WHEN** 访问者从服务状态面板返回服务列表
- **THEN** 系统 MUST 以短过渡恢复服务列表和当前服务栏位
- **AND** 系统 MUST 保持工作台标题、关闭按钮和标题栏状态入口可用

#### Scenario: Agent 状态变化
- **WHEN** 悦灵助手从等待检测、连接检测中、不可用、可用或发送中状态切换
- **THEN** 系统 MUST 以短过渡更新右侧栏位中的 Agent 状态内容
- **AND** 系统 MUST NOT 打开额外悦灵助手弹窗
- **AND** 系统 MUST NOT 展示“查看公告”或“查看维护说明”作为 fallback 按钮

#### Scenario: 减少动态下使用工作台
- **WHEN** 用户系统偏好为减少动态且访问者操作社团服务工作台
- **THEN** 系统 MUST 停止工作台内部位移、缩放、模糊和循环扫描动画
- **AND** 系统 MUST 保留静态选中态、状态入口反馈和右侧内容可见性
