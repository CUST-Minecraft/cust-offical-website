## ADDED Requirements

### Requirement: 社团服务入口使用工作台隐喻
官网 SHALL 将全站右下角服务集合入口展示为“社团服务”触发器。触发器 MUST 使用工作台方块风格图标表达服务集合，不得在触发器中展示文档中心、悦灵助手或其他具体服务特征。

#### Scenario: 查看社团服务触发器
- **WHEN** 访问者查看页面右下角服务入口
- **THEN** 系统 MUST 展示“社团服务”主标题
- **AND** 系统 MUST 展示工作台方块风格图标
- **AND** 系统 MUST 在“社团服务”下方展示“x 项服务可用”或等价服务数量文案
- **AND** 系统 MUST NOT 在触发器中展示书架、悦灵头像或其他具体服务特征作为服务预览

#### Scenario: 滚动到页尾
- **WHEN** 访问者滚动到站点页尾区域
- **THEN** 社团服务触发器 MUST 保持在页尾上方
- **AND** 社团服务触发器 MUST NOT 与页尾内容重叠

#### Scenario: 统计社团服务数量
- **WHEN** 系统计算社团服务触发器中的服务数量
- **THEN** 系统 MUST 统计左侧服务列表中的可展示服务入口
- **AND** 系统 MUST NOT 将面板级服务状态入口计入该服务数量

### Requirement: 社团服务入口具有轻微呼吸高光
社团服务触发器 SHALL 持续展示类似附魔书的按钮表面光亮，以提示该入口可交互。系统 MUST 在面板打开、用户悬停或聚焦触发器时停止流动动画并保留稳定表面光；当用户偏好减少动态时，系统 MUST 停止动画但保留静态光效。

#### Scenario: 展示可交互光效
- **WHEN** 访问者查看社团服务触发器
- **THEN** 系统 MUST 在触发器按钮表面展示内发光或掠光效果
- **AND** 光亮效果 MUST NOT 主要表现为按钮外边框发光
- **AND** 光亮效果 MUST NOT 造成按钮位置、尺寸或文本布局变化

#### Scenario: 面板打开或用户减少动态
- **WHEN** 社团服务工作台已经打开
- **THEN** 系统 MUST 停止流动动画并保留稳定表面光
- **AND** 当用户系统偏好为减少动态时，系统 MUST 停止动画并保留静态光效

#### Scenario: 光亮状态切换
- **WHEN** 触发器从待机流动光效进入打开、hover 或 focus 状态
- **THEN** 系统 MUST 通过短过渡切换为稳定表面光
- **AND** 过渡 MUST NOT 造成按钮位置、尺寸或文本布局变化

### Requirement: 社团服务工作台展示可选择服务列表
官网 SHALL 将服务集合展示为居中的社团服务工作台面板。左侧服务列表 MUST 只包含可选择并使用的服务入口，当前包括文档中心和悦灵助手。

#### Scenario: 打开社团服务工作台
- **WHEN** 访问者点击右下角“社团服务”触发器
- **THEN** 系统 MUST 在页面中间展示社团服务工作台面板
- **AND** 系统 MUST 将面板标题展示为“社团服务”或“社团服务工作台”
- **AND** 系统 MUST 保留右下角触发器作为打开入口
- **AND** 系统 MUST 展示社团服务列表和当前服务栏位，而不是继承上一次打开的服务状态面板
- **AND** 系统 MUST NOT 使用“快捷工具”作为用户可见主标题

#### Scenario: 查看左侧服务列表
- **WHEN** 访问者打开社团服务工作台
- **THEN** 系统 MUST 在左侧服务列表中展示“文档中心”和“悦灵助手”
- **AND** 系统 MUST 将文档中心标识为外部服务
- **AND** 系统 MUST 将悦灵助手标识为站内服务
- **AND** 系统 MUST 保持“文档中心”位于“悦灵助手”上方
- **AND** 系统 MUST NOT 将“社团服务状态”或“服务状态”展示为左侧可选择服务项

#### Scenario: 关闭社团服务工作台
- **WHEN** 社团服务工作台面板已经打开
- **THEN** 系统 MUST 提供明确关闭方式
- **AND** 系统 MUST 支持点击遮罩或按下 Escape 关闭面板
- **AND** 系统 MUST 在关闭后保持当前页面路由不变

### Requirement: 服务状态作为面板级状态入口
社团服务工作台 SHALL 将服务状态展示为面板级状态入口，而不是左侧服务列表项。状态入口 MUST 展示在线计数或摘要，并在激活后使用整个工作台内容区展示服务状态信息。

#### Scenario: 查看面板级服务状态
- **WHEN** 访问者打开社团服务工作台
- **THEN** 系统 MUST 在标题栏右侧展示服务状态入口
- **AND** 状态入口 MUST 展示在线数量、状态摘要或等价健康状态信息
- **AND** 状态入口 MUST 与关闭按钮保持清晰区分

#### Scenario: 打开服务状态面板
- **WHEN** 访问者点击或激活面板级服务状态入口
- **THEN** 系统 MUST 在社团服务工作台内容区展示服务状态面板
- **AND** 服务状态面板 MUST 展示在线数量、服务状态摘要和服务列表
- **AND** 系统 MUST 暂时隐藏左侧服务列表和右侧服务栏位的左右分栏结构
- **AND** 系统 MUST NOT 将该动作表现为切换左侧服务列表项
- **AND** 服务状态面板 MUST NOT 展示“查看维护说明”或等价维护页跳转按钮

### Requirement: 悦灵助手离线态聚焦 Agent 可用性
悦灵助手在社团服务工作台右侧栏位中 SHALL 展示 Agent 可用性。Agent 不可用时，系统 MUST 只说明不可用状态和原因，不得展示额外跳转按钮。

#### Scenario: Agent 服务不可用
- **WHEN** 访问者选择“悦灵助手”且 `/api/agent/status` 返回不可用或请求失败
- **THEN** 系统 MUST 在右侧栏位展示悦灵助手不可用提示
- **AND** 系统 MUST 展示 Agent 不可用原因或连接失败说明
- **AND** 系统 MUST NOT 将“查看公告”作为主要 fallback 按钮展示
- **AND** 系统 MUST NOT 展示“查看维护说明”作为 fallback 按钮

#### Scenario: Agent 服务可用
- **WHEN** 访问者选择“悦灵助手”且 `/api/agent/status` 返回可用
- **THEN** 系统 MUST 在右侧栏位展示悦灵助手站内工具 UI
- **AND** 该 UI MUST 至少提供常用指令或对话入口中的一种可操作内容
- **AND** 系统 MUST NOT 从社团服务工作台再打开额外的悦灵助手弹窗

### Requirement: 社团服务工作台适配移动端
社团服务工作台 SHALL 在移动端保持可读、可点按且不横向溢出。系统 MUST 根据视口调整服务列表、状态入口和右侧栏位布局。

#### Scenario: 移动端打开社团服务工作台
- **WHEN** 访问者在移动端视口打开社团服务工作台
- **THEN** 系统 MUST 将面板宽度限制在视口安全范围内
- **AND** 系统 MUST 让服务列表、状态入口和当前服务栏位均可读
- **AND** 系统 MUST NOT 产生横向滚动或文本明显溢出

#### Scenario: 移动端使用服务状态入口
- **WHEN** 访问者在移动端查看社团服务工作台
- **THEN** 系统 MUST 保持服务状态入口可见或可通过标题区域自然访问
- **AND** 状态入口和主要操作按钮 MUST 具备可触控尺寸
